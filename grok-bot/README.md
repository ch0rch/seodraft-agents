# seodraft SEO content desk for Grok Bot

A ready-made [Grok Bot](https://x.ai/bot) template that turns your bot into an SEO content desk powered by [seodraft](https://seodraft.app), the SEO agent that writes without AI slop.

**Template:** https://x.ai/bot/OkT4Dbjy4xVf7oVBCr8hL

## What it does

- Plans blog topics with measured search volume from your own DataForSEO account
- Researches the SERP for each topic and writes a brief
- Drafts from evidence you supply, with no invented stats, quotes, or customers
- Runs seodraft's quality gate (filler, keyword placement, cannibalization) before you see the draft
- Delivers only after you approve, as Markdown, HTML, or a git draft

## Set up

1. Open the template link above and create your bot from it.
2. Grok Bot templates don't carry custom MCP servers, so the bot's first conversation walks you through connecting seodraft. If you want to do it yourself, tell the bot: `Add this MCP server: https://seodraft.app/mcp`, then complete the seodraft sign-in.
3. Don't have a seodraft account? Start the 7-day free trial at https://seodraft.app. No card needed.

The template includes the same two skills as this repository's [`skills/`](../skills) folder: `getting-started-seodraft` and `seodraft-content-desk`.
